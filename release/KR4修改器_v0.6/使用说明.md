# KR4 修改器 使用说明

版本：面板 v0.6 / 内核 DLL 构建 v24
适用游戏：Kingdom Rush Vengeance（Steam 版，appid 1367550）
最后更新：2026-11-21

---

## 一、这是什么

这是一个注入式内存修改器。`kr4injector.exe` 把 `kr4mod.dll` 注入游戏进程，DLL 在游戏内挂一个 ImGui 覆盖层面板，实时改写内存款实现金币、生命、经验、速率等效果。

特点：

- 不修改游戏任何文件，不动存档，游戏退出即完全失效；
- 纯本地运行，无网络请求；
- 支持热卸载（面板里按 END），卸载后可重新注入，不必重启游戏。

## 四、快速上手（3 步）

1. **先开游戏**：Steam 库中启动 Kingdom Rush Vengeance，进入主菜单或关卡内。
2. **再注入**：双击 `启动修改器.bat`。出现下面这行就成功了：
   ```
   [+] DLL loaded in pid 12345 (remote HMODULE=0x7ffb...)
   ```
3. **回游戏按 INSERT**：面板出现在左上角，再按一次 INSERT 隐藏。

> 建议顺序是先开游戏再注入。注入器也支持等待模式（`--wait`），即使先运行脚本，它也会等游戏进程出现后再注入。

### 不用 bat、手动命令行注入

在文件所在目录打开 PowerShell 或 CMD：

```bat
kr4injector.exe --name "Kingdom Rush Vengeance.exe" --dll "kr4mod.dll"
```

参数说明：

| 参数 | 说明 |
| --- | --- |
| `--name <进程名>` | 按进程名查找目标，默认就是 `Kingdom Rush Vengeance.exe` |
| `--pid <PID>` | 直接指定进程 ID，游戏开了多个实例时用得上 |
| `--dll <路径>` | DLL 路径，默认同目录 `kr4mod.dll` |
| `--wait <秒>` | 等待进程出现的超时时间，超时仍没找到则退出 |

退出码：

| 退出码 | 含义 |
| --- | --- |
| 0 | 注入成功 |
| 1 | 参数错误 |
| 2 | 没找到目标进程 |
| 3 | 打开进程 / 分配内存 / 写内存失败（通常是权限不足） |
| 4 | 创建远程线程失败 |
| 5 | LoadLibraryW 返回 NULL，即 DLL 在游戏内加载失败（架构不符或缺依赖） |

## 五、面板功能

面板标题为「KR4 修改器 v0.6 （全部功能）」，共三个分组，右侧有滚动条。

**通用流程：先点「一键安装全部」把 Hook 装好，再点「全部开启」生效。** 只开开关不装 Hook 是没有效果的。

### 金币相关

| 控件 | 说明 |
| --- | --- |
| 开启 / 关闭金币锁定 | 锁定当前金币值不变，花钱也不减少 |
| 金币数输入框 | 锁定目标值，修改后立即生效 |
| 金币倍率（1–100，滑块） | 只放大**增加**的金币，花钱不会被放大，符合直觉 |

### 英雄相关

| 控件 | 说明 |
| --- | --- |
| 英雄经验锁定 | 英雄获得的经验固定为目标值，一次升级 |
| 经验倍率（1–10） | 经验获取量放大 |
| 技能点免消耗 | 学技能不扣技能点 |
| 升级点锁定 | 升级点数保持不减 |

### 基础功能

| 控件 | 说明 |
| --- | --- |
| 一键安装全部 | 一次性安装金币、生命、单位、经验、技能、升级点共 6 处 Hook |
| 全部开启 / 全部关闭 | 批量切换所有功能开关，不改 Hook 安装状态 |
| 生命锁定 + 血量输入 | 塔和单位血量锁定（默认 9999） |
| 友军无敌 / 一击必杀 | 我方不掉血；对敌一击致死 |
| 伤害倍率 | 我方输出伤害放大 |
| 游戏速率（0.10–4.00x）+ 1.00x 按钮 | 全局游戏速度缩放，1.00x 按钮一键复位 |

> 游戏速率说明：速率接管后内部会一直走连续虚拟时间线，因此在 1.00x、2.50x、4.00x、0.50x 之间来回切换都不会出现时间跳变或卡死。想彻底恢复真实时间，用 END 卸载 Hook 或退出游戏。

## 六、快捷键

| 按键 | 作用 |
| --- | --- |
| `INSERT` | 显示 / 隐藏面板（面板隐藏时功能照常生效） |
| `END` | 卸载全部 Hook：还原被改写的原始指令、释放注入代码，游戏立即回到干净状态 |

END 卸载是安全卸载：内部会延迟到本轮渲染结束才真正还原，不会把游戏写崩。卸载后可以再注入新版本 DLL，**不需要重启游戏**。

## 七、进阶：文件命令通道

不想手点面板时，可以往文本文件里写一行命令来驱动 DLL，适合脚本化与远程批量操作。

- 命令文件：`%TEMP%\kr4mod_cmd.txt`（即 `C:\Users\<用户名>\AppData\Local\Temp\kr4mod_cmd.txt`）
- 日志文件：`%TEMP%\kr4mod.log`（想换位置可设环境变量 `KR4MOD_LOG`）
- 触发规则：**文件内容发生变化才执行一次**，写完全一样的命令不会重复执行
- 首次轮询会丢弃文件里已有的残留命令（防止上一次会话的旧命令被重放），所以注入后请**重新写一次**命令文件

常用命令：

| 命令 | 作用 |
| --- | --- |
| `hookall` | 安装全部 Hook |
| `allon` / `alloff` | 全部功能开 / 关 |
| `mon` / `moff` | 金币锁定开 / 关 |
| `mset 1000000` | 设置金币数 |
| `mmul 10` | 金币倍率 |
| `hmon` / `hmoff` | 生命锁定开 / 关 |
| `hset 9999` | 设置锁定血量 |
| `allyon` / `allyoff` | 友军无敌开 / 关 |
| `killon` / `killoff` | 一击必杀开 / 关 |
| `dmul 5` | 伤害倍率 |
| `speed 2.5` | 游戏速率（0.10–4.00） |
| `xmon` / `xmoff` | 英雄经验锁定开 / 关 |
| `xmul 5` | 经验倍率 |
| `skon` / `skoff` | 技能点免消耗开 / 关 |
| `upon` / `upoff` | 升级点锁定开 / 关 |
| `upamt 10` | 升级点数值 |
| `status` | 把当前状态写进日志 |
| `unhook` | 卸载全部 Hook（等价于按 END） |

`%TEMP%` 下还有两个辅助标志文件：

- `kr4mod_render.off`：存在时 DLL 完全不碰图形管线（面板不画），用于排查"画面异常是不是覆盖层造成的"；
- 命令通道与日志均为纯文本，可随时删除。

PowerShell 写命令的写法：

```powershell
Set-Content -Path "$env:TEMP\kr4mod_cmd.txt" -Value "hookall" -Encoding ascii
Start-Sleep -Milliseconds 500
Set-Content -Path "$env:TEMP\kr4mod_cmd.txt" -Value "allon" -Encoding ascii
```

## 八、换电脑运行注意事项

1. **拷贝整个文件夹**，不要只拷 dll。杀软报毒属正常现象（远程线程注入 + 内存改写是典型外挂行为特征），需要把文件夹加入信任或白名单。
2. **必须 64 位**：注入器与 DLL 都是 x64。若注入后提示退出码 5 / `LoadLibraryW returned NULL`，先确认游戏是 64 位进程。
3. **同一个游戏进程里只能有一个 `kr4mod*.dll` 实例**。重复注入会让两个覆盖层同时绘制同一块面板，表现为面板闪烁。换版本前请先按 END 卸载，或直接重启游戏。
4. **游戏版本不同可能失效**：Hook 依赖对游戏代码的特征匹配。本包在 1.16.4.0 上验证通过；若你的游戏是别的版本，面板的状态行会显示"未找到 / 安装失败"，此时需要针对该版本重新定位特征码并重新编译 DLL。
5. 游戏从 Steam 启动即可，无需替换任何游戏文件；本修改器不参与 Steam 校验，也不会被校验拉黑（不改文件、不注入网络栈）。

## 九、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 双击 bat 窗口一闪而过 | 正常，注入器执行完就退出。窗口里应能看到 `[+] DLL loaded`；用 CMD 手动运行可看清输出 |
| 提示进程未找到（退出码 2） | 游戏没启动，或进程名不是 `Kingdom Rush Vengeance.exe`。用任务管理器确认后改用 `--pid` |
| 退出码 3 / 打不开进程 | 权限不足，右键 bat「以管理员身份运行」 |
| 退出码 5 / DLL 加载失败 | 架构不符（游戏是 32 位）或目标机缺少 UCRT（Win7/8 装 KB2999226） |
| 注入成功但游戏没反应、按 INSERT 没面板 | 面板可能被隐藏了；确认游戏窗口在前台（覆盖层只画在游戏窗口上）；看 `%TEMP%\kr4mod.log` 是否有 `passthrough` 之类记录 |
| 面板文字出现问号 | 正常用字已补全；若个别生僻字出现方块，属字体表限制，不影响功能 |
| 面板闪烁 / 出现两套面板 | 注入了两个以上 kr4mod DLL。按 END 卸载后重启游戏，只注入一个 |
| 功能打开但数值没变 | 没装 Hook。先点「一键安装全部」再「全部开启」，或发 `hookall` 命令 |
| 画面异常、怀疑覆盖层导致 | 在 `%TEMP%` 下新建空文件 `kr4mod_render.off`，DLL 将完全不绘制，用于定位问题 |
| 想彻底恢复原状 | 游戏内按 END，或直接退出游戏（DLL 随进程结束消失，无需清理） |

## 十、清理

- `%TEMP%\kr4mod_render.off`
- 修改器文件夹本身

游戏文件和存档从未被写入，无需任何还原操作。
